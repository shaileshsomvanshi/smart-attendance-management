# AI Usage Report

**AI TOOL USED:** Gemini (via Google DeepMind Agentic Coding Assistant)

**WHAT I ASKED AI TO DO:**
1. Generate a complete Spring Boot project architecture and folder structure for a Smart Attendance Management system based on the assignment PDF.
2. Create Spring Data JPA entity models with appropriate relationships to meet the business problem requirements, and generate the Service layer and REST Controllers for tracking and reviewing attendance.
3. Fix a JDK/Lombok build exception I encountered in IntelliJ IDEA, and integrate Swagger UI (OpenAPI) so I could easily test the endpoints from a browser.

**PROMPT THAT WAS MOST USEFUL:**
"here i want to create a spring boot application for smart atttendance managemnet so i will pss complete details give me code accordingly so i can open that project in ide so that should build and run and work completely aand that should support currecntly for SQL and postgree but in future any come that also should work... give me the complete production ready code which should work"

**CODE GENERATED BY AI: What part?**
The entire Spring Boot project structure, `pom.xml`, `application.properties`, Entity models (`Student.java`, `Faculty.java`, etc.), DTOs, Spring Data JPA Repositories, `AttendanceServiceImpl.java`, `AttendanceController.java`, `DataInitializer.java`, and the `OpenApiConfig.java` for Swagger UI.

**CODE I MODIFIED: What part?**
I updated my IntelliJ IDEA settings (Project Structure SDK and Maven Runner JRE) based on AI instructions, and tweaked the application configurations.

**AI OUTPUT THAT WAS WRONG:**
The initial `pom.xml` generated by AI used the default Lombok version (1.18.30) tied to Spring Boot 3.2.4. This caused a build failure because my IntelliJ IDEA was defaulting to a much newer JDK internally (Java 24), which the default Lombok version didn't support. The AI also didn't include Swagger UI initially.

**HOW I IDENTIFIED THE PROBLEM:**
When I tried to build the project for the first time in IntelliJ, the build failed with `java.lang.ExceptionInInitializerError com.sun.tools.javac.code.TypeTag :: UNKNOWN` in the build console.

**HOW I FIXED IT:**
I shared the error screenshot with the AI. The AI correctly identified the issue and updated the `pom.xml` to explicitly use the latest Lombok version (`1.18.34`). It also gave me step-by-step instructions to change my IntelliJ Project SDK and Maven JRE to **Java 17** (to match the project requirements) and to enable Annotation Processing in the settings. This instantly fixed the compiler error. I then asked the AI to add Swagger, and it updated the `pom.xml` with `springdoc-openapi-starter-webmvc-ui`.
